# 独立项目模板

此目录提供可复制到新项目的通用协作规则。它不携带任何项目事实、资源清单、凭据或已获授权的操作。

先由项目负责人定义项目规则、任务入口、来源记录、审核与采纳责任，以及历史归档方式。模板中的要求描述目标行为；只有已实现并启用的受管入口才可能对其执行范围形成程序约束。

框架源码中的 README.md 和 docs/CLI.md 给出实际入口。先初始化一个空项目，再由负责人显式分配凭据及输出范围。把本目录的 AGENTS.md 放到新项目只提供轻量说明，不会自动安装任何hook或注入全部历史。

日常启动只读轻量规则与当前 STATE 导航，再按任务问题检索历史。阶段手账、全量索引、设计规范和完整账本都按需查，不默认全文注入。各工具自己的自动加载机制需在接入时另外核实，不能只靠缩短一个文件宣称已解决所有上下文负担。
