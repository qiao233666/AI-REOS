# 本地机器记忆与确定性维护

版本目标0.3.0。延续已确认的三类责任及共同支撑，机器存储按检索与追溯设计；人的手账仍是同一正式记录的派生视图。本文件不授予未来迁移、外发资料或付费调用权限。0.3的片段、正文自动索引和现有技术借用见[MACHINE_MEMORY](MACHINE_MEMORY.md)。

## 实现选择

正式对象、历史版本、快照及采纳规则继续由现有SQLite保存。检索采用SQLite FTS5倒排索引，替换逐条扫描正文的原型；索引覆盖历史版本。索引可从正式记录重建，不能改变正式事实。

语义通道采用可选的FastEmbed本地CPU编码器和Qdrant Client嵌入式数据库，使用固定模型、缓存和确定性的排序融合。词面通道和语义通道并行找候选；当前版本、旧版、失败和撤回均可被找到。Qdrant、向量和编码模型是可重建派生数据，不能代替来源。

默认不下载模型、不联网、不调用对话模型。启用语义通道须显式安装可选依赖并预置模型到指定目录。缓存只处理新增或变化的版本，查询单独编码。模型身份、维度与配置变化不能混用旧向量。嵌入式Qdrant只由一个本地进程持锁使用；框架用同一权威数据库的写事务串行化索引访问，不宣称分布式支持。

## 模型实际收到什么

返回带来源、版本、现在复用状态的短正文；同时带回支持、反驳、争议、替代及审核关系。总显示预算适用于正文及状态字段，来源清单单独计数。未显示内容提供精确id/rev补取，未命中不推出不存在，图截断明确阻止不加限定的复用。

## 输入与并行收据

文件输入在创建任务时绑定路径、SHA-256及快照；对象输入绑定准确版本；纯描述显式标为note。收据必须覆盖声明输入，不能只覆盖搜索命中的资料。输入内容变化需重新裁定任务，刷新搜索不会自动接受新输入。

输入默认usage=basis，其当前依据状态也影响任务成果的复用；reference表示拿来重审或反驳的材料，不背书原结论。两种用途均固定字节/版本，并带入显式来源、争议、更正和审核。文件输入按规范路径与摘要找回已登记artifact身份，因此不会因换成文件写法漏看既有异议。查询命中、任务输入及本任务产物统一展开关系，最多200项；截断会阻止不加限定地继续使用收据。候选排名的top-k截断另行提示，不等于宣称图已完整。

普通收据逐项核对已用版本、来源、任务及其显式关系；无关全库更新不再自动令它失效。新增可能相关但尚未建立显式关联的资料作为增量提示返回，不能据此保证没有隐含冲突。高风险任务可选择strict模式，保留全库更新即需重新准备的策略。

## 不用模型维持框架

新增一次交付结果后，程序完成文件快照、主张登记、上下文刷新、版本交付和可恢复的步骤记录。核查者提供一次实际意见后，程序完成准确版本核对；统筹作出采纳决定后程序逐项采纳、阶段说明和视图发表。自动流程不能代替内容判断或冒用其他角色凭据。

组合动作以持久请求身份分步骤执行；重试不会重建交付或重复启动工具。部分失败保留已提交步骤及明确状态，重试从同一请求恢复。初次缺失输入或来源变化时停止，不自动放宽约束。

## 评测

源码内仅含合成评测及公开格式示例。真实历史摘录、原文件路径和自然问法保存在独立私有评测目录，不写入空框架Git。评测保存语料/题目摘要、检索配置、已标注材料Hit@k与MRR、逐题定位和未知；未标注材料不作为负例。

小规模基准只判断指定历史材料是否找回，不证明整体召回率、科学真假或方法最优。关键词、混合检索和原型基线在同一冻结语料上比较；模型和参数的选择不能只凭同一小样本分数下结论。

## 保留的边界

本轮不建设不可信代理隔离服务、不迁移研究项目、不让记忆组件自动判定科学因果。自动关系抽取、全量科研资料索引及长期性能基准另行评估；当前以明确来源和既有关系为准。
