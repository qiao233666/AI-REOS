# Plan 模板（HOW）

Plan 回答"怎么做"，仅在需要时编写；Task Spec 回答 WHAT/WHY。

## 何时才需要 Plan

满足任一条件才写 Plan：

- 架构改动（模块边界、依赖方向发生变化）。
- 跨模块改动（影响多个子系统的协作）。
- 接口或 schema 变更（对外契约发生变化）。
- 昂贵实验（需要严谨的部署 / 续跑 / 资源安排）。
- 预计改动多个关键文件。

不满足上述条件时，`plan.required` 保持 false，直接执行。

- Plan 只描述 HOW，不重复 WHAT 与验收条件。

- 涉及科学结论时区分 FACT / INFERENCE / HYPOTHESIS / UNKNOWN；相关性不得写成因果；未收敛结果不得当作连续介质极限。
